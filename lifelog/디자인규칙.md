# LifeLog 디자인 시스템 규칙 (LifeLog Design Specifications)

> 본 문서는 LifeLog 프로덕트의 와이어프레임 화면을 상용 서비스 수준으로 정밀 구현하기 위한 전용 디자인 시스템 및 컴포넌트 명세서입니다.  
> 선정된 **Direction 2: Soft Pastel Sunrise & Warm Tactile**을 기반으로 하며, Figma 무손실 임포트(1920×1080) 규격을 엄격히 준수합니다.

---

## 1. 디자인 아이덴티티 및 방향성 (Design Identity)

* **테마명**: **Direction 2 — Soft Pastel Sunrise & Warm Tactile**
* **콘셉트**:
  * 취업 및 커리어 준비 과정의 긍정적인 기대감을 담은 **따뜻한 일출(Sunrise)의 앰버/오렌지** 컬러 아이덴티티.
  * 차갑고 기계적인 디지털 인터페이스를 탈피하여, 자연스러운 종이 질감의 **웜 에그쉘(Warm Eggshell) 캔버스**와 부드러운 파스텔 톤 뱃지의 조화.
  * 정량적 데이터(연봉, 기간, 상승률)를 정교하고 신뢰감 있게 전달하는 고정밀 타이포그래피.

## 3. 타이포그래피 표준 (Typography System)

* **서체 단일화**: **`Pretendard`** 전 영역 단일 적용 (영문 모노스페이스 혼용 금지)
* **숫자 고정폭 강제**:
  ```css
  font-family: 'Pretendard', sans-serif;
  font-variant-numeric: tabular-nums;
  font-feature-settings: "tnum" 1, "cv02" 1, "cv03" 1, "cv04" 1;
  ```

| 계층 | 폰트 크기 | Weight | 용도 |
| :--- | :--- | :--- | :--- |
| **Page Main Title** | `25px` | 850 (Heavy) | 상단 페이지 타이틀 (`연봉 시뮬레이터 — 조건 변경 및 비교`) |
| **Section Title** | `17px ~ 18.5px` | 850 (Heavy) | 좌측 `변경해볼 조건 선택`, 우측 `연차별 예상 성장 곡선 시뮬레이션` |
| **Hero Numbers** | `26px` | 900 (Black) | 초봉 수치 (`3,400만 ~ 3,800만 원`, `3,900만 ~ 4,300만 원`) |
| **Card Header/Label** | `13.5px` | 800 (Bold) | 조건 단계명 (`실무 인턴십 경험` 등) |
| **Body & Subtitle** | `12px ~ 13px` | 600 ~ 750 | 스펙 텍스트, 안내 텍스트, 버튼 라벨 |
| **Micro Badges** | `11px ~ 11.5px` | 750 ~ 850 | 캡슐 뱃지, 상태 태그, 리프트 뱃지 |

## 5. 핵심 공통 컴포넌트 상세 명세

### 5.1 상단 스펙 기준선 독 (`baseline-spec-dock`)
* **위치**: 좌측 조작 콘솔 내부 최상단에 배치 (상단과 좌측 간 40px 인지적 단절 해결)
* **스타일**:
  * 배경: `linear-gradient(180deg, #fffcf8 0%, #faf8f3 100%)`
  * 테두리: `1px solid #ede8de`, 라운드: `12px`, 패딩: `13px 15px`
  * 태그: `내 현재 조건 기준선` (코랄 틴트 `#ffedd5`, 글자 `#ea580c`)
  * 직무 표시: `희망 직무: 백엔드 개발자`

### 5.2 조건 변경 셀렉터 (`condition-step-box`)
* **기본 상태**:
  * 배경: `#faf9f6`, 테두리: `1px solid #edebe4`, 라운드: `10px`
  * 상단 메타 행: `[0X 카테고리]` 파스텔 캡슐 뱃지 + `단계명` + `현재 보유 상태`
  * 드롭다운 정적 인풋: `#ffffff` 배경, 우측 `▼` 벡터 아이콘
* **선택 중 (Active Selection) 상태 (Frame 08)**:
  * 배경: `#fffcf8`, 테두리: `1.5px solid #ea580c`, 그림자: `0 4px 14px rgba(234, 88, 12, 0.08)`
  * 상단 우측: 오렌지 솔리드 뱃지 `선택 중` (`#ea580c`, 흰색 글씨)
  * 인풋 필드: 오렌지 하이라이트 그라디언트 (`linear-gradient(#fffaf4, #ffedd5)`)
* **상태 반영 안내 텍스트 (`reflected-result-text`)**:
  * **절대 원칙**: 외곽 박스, 테두리, 배경색 일절 금지 (텍스트 단독 노출)
  * 스타일: `color: #059669; font-size: 11.5px; font-weight: 700; margin-top: 5px;`
  * 내용: `✓ 인턴 경험 6개월이 반영된 결과입니다.`

### 5.3 KPI 결과 지표 카드 (`kpi-stat-box`)
* **기본 카드 (내 현재 조건 예상 초봉)**:
  * 배경: `#faf9f6`, 테두리: `1px solid #edebe4`, 수치 색상: `#6a6875`
* **활성 시뮬레이션 카드 (인턴 6개월 추가 시 예상 초봉)**:
  * 배경: `linear-gradient(135deg, #fff7ed 0%, #ffffff 100%)`
  * 테두리: `1.5px solid #ea580c`
  * 수치 색상: `#ea580c` 볼드 수치 (`3,900만 ~ 4,300만 원`)
  * **리프트 뱃지 (`positive-lift`)**:
    * `▲ +500만 원 상승 (+13.9%)`
    * 배경: `linear-gradient(135deg, #ffedd5 0%, #fee2e2 100%)`
    * 테두리: `1px solid rgba(234, 88, 12, 0.3)`, 글자: `#c2410c`, 굵기: `850`

### 5.4 연차별 예상 성장 곡선 시뮬레이션 차트 (SVG)
* **캔버스 규격**: `viewBox="0 0 984 380"`, 높이 `380px`
* **기준선 (Baseline Spline)**:
  * 곡선: `stroke="#94939c" stroke-width="2.5" stroke-dasharray="5 4"`
  * 노드 칩: 은은한 슬레이트 라벨 (`현재 3,600만`, `현재 4,450만`, `현재 5,450만`)
* **가상 시뮬레이션선 (Simulated Spline)**:
  * 곡선: `stroke="url(#f8StrokeGrad)" stroke-width="3.5"` (오렌지/앰버 그라디언트)
  * 노드 칩: Sunrise 오렌지 솔리드 필 (`변경 후 4,100만`, `변경 후 4,900만`, `변경 후 5,900만`)
* **성장 격차 면 채우기 (Delta Area Gradient)**:
  * 곡선 사이 채우기: `<polygon fill="url(#f8AreaGrad)"/>`
  * 그라디언트: `#ea580c (투명도 0.25)`에서 `#f59e0b (투명도 0.03)`으로 자연 감쇄
* **상승 마커**: 차트 내 `+500만 원 차이` 오렌지 뱃지 노출

### 5.5 하단 액션 버튼
* **좌측 비교 버튼**: `다른 선택지와 한눈에 비교하기 →` (오렌지/앰버 그라디언트)
* **우측 대시보드 저장 버튼**: `이 목표를 대시보드에 저장 →` (오렌지 솔리드 `#ea580c`, 굵기 800)

## 6. 프레임별 상태 정의 (State Definitions)

* **Frame 07 (연봉 시뮬레이터 — 초기 상태)**:
  * 좌측 조건 콘솔: 상단 내 현재 조건 기준선(볼드 헤딩, 무배경) + `[+3개 더보기 ▾]` 버튼, 5개 조건 모두 미선택 기본 상태 (`+ 실무 인턴십 기간 선택` 등)
  * 우측 상단 KPI: 우측 카드가 점선 가이드 박스(`kpi-guide-box`, "← 왼쪽에서 조건을 선택하면 가상 시뮬레이션 곡선이 표시됩니다")로 노출
  * 우측 차트: 기준선 곡선 1개만 단독 렌더링
* **Frame 07-P (연봉 시뮬레이터 — 내 등록 스펙 전체보기 플로팅 팝오버)**:
  * `[+3개 더보기 ▾]` 버튼 클릭 시 기준선 독 하단에 플로팅 오버레이되는 전용 피그마 컴포넌트/상태 아트보드
  * 총 6개 스펙을 4개 카테고리(학력/전공, 공인 자격증, 어학 성적, 활동/경력)로 분류 렌더링
* **Frame 08 (연봉 시뮬레이터 — 인턴십 6개월 시뮬레이션 결과)**:
  * 상단 헤더: `현재 조건으로 초기화` 버튼 노출
  * 좌측 1번 조건: `스타트업 백엔드 인턴 6개월` 선택 상태 + `선택 중` 태그 + `✓ 인턴 경험 6개월이 반영된 결과입니다.` 노출
  * 우측 상단 KPI: `인턴 6개월 추가 시 예상 초봉` 활성 카드 + `▲ +500만 원 상승 (+13.9%)` 뱃지 노출
  * 우측 차트: 기준선(회색 점선) + 조건 변경 가상선(오렌지/앰버 곡선) + 델타 면 채우기 동시 렌더링
  * 우측 하단: `준비 소요 기간` (불필요한 인위적 2번째 줄 제거, 정직한 1줄 제공) + `분석 참고 안내` 2열 카드 및 대시보드 저장 버튼 노출

## 8. Figma UI/UX 디자인 방어 설계 규칙 (Design Defensiveness Standards)

실제 데이터 변동 및 극단적 조건 비교 상황에서도 Figma 프레임의 정렬선과 시각적 완성도가 깨지지 않도록 다음 5대 방어 원칙을 준수합니다.

1. **스펙 기준선의 마이크로 태그 칩(Chip) 모듈화**:
   - 텍스트 단순 나열(`·`)을 금지하고, 개별 스펙을 독립된 화이트 칩(`spec-tag-chip`)으로 감싸 분리.
   - Auto-Layout Wrap을 적용하되, 스펙이 4개 이상일 때는 최대 2줄 이내로 고정하고 요약 뱃지(`+N개 더보기 ▾`) 컴포넌트로 축약하여 상하 여백 붕괴를 차단.
2. **조건 카드의 모듈러 높이 유지 (Modular Sizing)**:
   - 조건 활성화 시 특정 카드만 아래로 길어져 수직 리듬(Vertical Rhythm)이 파괴되는 것을 방지.
   - 카드를 키우지 않고 **테두리(1.5px Sunrise 오렌지)와 은은한 표면 틴트(Peach Wash)** 중심의 시각적 포커스 대비로 상태를 명확히 표현.
3. **차트 툴팁 상하 스태거링 (Staggered Tooltips)**:
   - 두 곡선 간격이 좁아지거나 연차별 데이터가 밀집될 때 발생하는 칩 간 텍스트 겹침(Collision)을 원천 차단.
   - 기준선 노드 라벨(`현재 3,600만` 등)은 곡선 **아래쪽**, 시뮬레이션 가상선 노드 라벨(`변경 후 4,100만` 등)은 곡선 **위쪽**으로 상하 분리 배치.
4. **연봉 수치 타이포그래피 위계 정렬**:
   - 범위(`3,900만 ~ 4,300만 원`)보다 사용자가 직관적으로 확인해야 하는 **단일 대표 예상치(`4,100만 원 선`)와 상승 폭(`▲ +500만 원 상승 (+13.9%)`)**을 시각적 주인공으로 격상.
5. **좌우 시각적 밀도 균형 & 시선 유도선 (Visual Bridge)**:
   - 좌측 폼에 시선이 갇히지 않도록 좌측 조건 카드의 패딩을 정돈하여 여백 호흡(Breathing Space)을 확보.
   - 좌측 활성 조건(인턴십)과 우측 가상선/KPI/차트 곡선에 동일한 **Sunrise 오렌지(`#ea580c`) 시그니처 컬러**를 관통시켜 시선이 자연스럽게 좌측 조작에서 우측 결과로 이어지도록 유도.
