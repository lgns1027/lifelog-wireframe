# 화면 구조도 (Information Architecture)

## 1.0 공통 영역 (상단 고정 메뉴 바 및 공통 화면)

- **1.1 상단 고정 메뉴 바:** 화면 맨 위에 상시 위치하여 언제든지 대시보드, 내 스펙·진단, 연봉 시뮬레이터, 커리어 경로, 채용 기회 탭으로 자유롭게 이동할 수 있도록 돕는 다섯 개의 조작 메뉴와 서비스 로고이다.
- **1.2 사용자 계정 및 세션 상태:** 상단 메뉴 바 오른쪽에 위치하여 로그인 여부를 보여준다. 비회원 상태에서는 로그인 및 회원가입 버튼이 표시되며, 로그인 완료 후에는 사용자의 고유 활동명(닉네임)과 원형 심볼이 나타난다.
- **1.3 서비스 로고 및 첫 화면 복귀:** 상단 메뉴 바 좌측의 'LifeLog' 로고를 누르면, 로그인 사용자는 메인 커리어 대시보드로, 비회원 사용자는 서비스 안내 화면으로 즉시 이동한다.

## 2.0 대시보드 (홈 화면)

- **2.1 대시보드 진입 안내 화면 (처음 방문)**
    - **2.1.1 3단계 이용 방법 안내 영역:** 처음 접속한 사용자에게 막연한 진로 고민 대신 데이터 기반으로 합리적인 결정을 내리는 3단계(내 조건 등록 ➔ 예상 연봉 기준선 확인 ➔ 준비 선택지 비교 및 목표 설정) 과정을 한눈에 안내한다.
        - 버튼 1: '내 스펙으로 진단 시작하기' ➔ 내 조건 등록 화면으로 즉시 이동한다.
    - **2.1.2 진단 결과 미리보기 영역:** 실제 진단을 완료했을 때 마주하게 될 백엔드 개발자 기준의 예상 연봉 범위(3,400만 ~ 3,800만 원)와 동일 집단의 첫 취업 및 이직 통계 요약을 미리 보여주어 사용자의 자발적 진단 참여를 이끈다.
- **2.2 커리어 대시보드 (진단 완료 상태)**
    - **2.2.1 현재 내 조건 기준 예상 연봉 요약 카드:** 사용자가 입력한 실제 스펙을 바탕으로 산출된 기준 예상 연봉(3,600만 원)을 큼직한 숫자로 보여준다. 상단에는 초봉, 3년 차, 5년 차 탭이 있어 연차별 연봉 추이를 전환해 볼 수 있으며, 하단에는 등록한 주요 스펙 한 줄 요약과 세전 기본급 기준 안내 문구가 표시된다.
        - 버튼 1: '내 스펙 수정' ➔ 기입력된 데이터를 유지한 채 내 조건 수정 화면으로 이동한다.
        - 버튼 2: '진단 결과 자세히 보기' ➔ 연봉 진단 결과 상세 화면으로 연결된다.
    - **2.2.2 다음 준비 목표 안내 카드:** 아직 시뮬레이터에서 목표를 정하지 않은 사용자에게 다음 행동을 권유하는 점선 테두리 카드이다.
        - 버튼 1: '시뮬레이터에서 목표 찾기' ➔ 연봉 시뮬레이터 화면으로 이동한다.
    - **2.2.3 내 스펙 변경 이력 타임라인:** 자격증 취득이나 어학 성적 갱신으로 연봉 계산이 상향 조정되었던 기록을 시간 순서대로 보여주어 성장의 성취감을 전달한다.
    - **2.2.4 저장한 항목 요약:** 사용자가 관심 경로로 저장해 둔 대표 이직 경로와 저장한 채용 공고의 핵심 요약을 카드 형태로 표시한다.
- **2.3 커리어 대시보드 (목표 설정 완료 상태)**
    - **2.3.1 선택한 준비 계획 카드:** 시뮬레이터에서 확정한 준비 목표(인턴십 6개월)와 목표 달성 시의 예상 연봉(3,850만 원)을 보여준다.
    - **2.3.2 할 일 체크리스트:** 목표를 달성하기 위해 실천해야 할 3가지 실행 과제(포트폴리오 문서화, 지원서 접수, 면접 대비)를 체크박스 형태로 제공하며, 사용자가 완료 여부를 직접 켜고 끌 수 있다.
        - 버튼 1: '맞춤 인턴 공고 확인하기' ➔ 해당 목표에 부합하는 공고 목록 화면으로 바로 연결된다.

## 3.0 내 스펙·진단 (조건 등록 및 연봉 확인)

- **3.1 내 조건 등록 및 수정 화면**
    - **3.1.1 기본 상태 및 희망 직무 입력 상자:** 현재 상태(졸업예정, 졸업, 재직 중 등)와 희망 직무(백엔드 개발자 등)를 정적 선택 상자로 손쉽게 고를 수 있다.
    - **3.1.2 학력 및 전공 입력 상자:** 최종 학력, 학교 소재지, 졸업 학점, 전공 계열, 주전공명을 입력한다.
    - **3.1.3 자격증 및 공인 어학 입력 상자:** 보유 자격증 칩을 누르거나 추가하고, 토익 등 공인 어학 성적을 기재한다.
    - **3.1.4 실무 경험 및 주요 활동 입력 상자:** 특정 직무에 얽매이지 않는 범용 구조로 프로젝트명, 수행 기간, 주요 역할, 핵심 기술 및 도구 태그를 자유롭게 입력한다.
    - **3.1.5 하단 실행 및 저장 영역:** 입력 정보의 안전한 보호를 고지하며 화면 이동을 제어한다.
        - 버튼 1: '임시 저장' ➔ 비회원은 로그인 화면을 거쳐 기기 내부 저장소 데이터를 서버에 보존하고, 회원은 즉시 저장한다.
        - 버튼 2: '예상 연봉 확인하기' ➔ 입력값의 유효성을 점검한 후 진단 결과 화면으로 넘어간다.
- **3.2 내 스펙 입력 오류 안내 화면**
    - **3.2.1 최종 학력 미선택 오류 알림:** 필수 항목인 최종 학력을 고르지 않고 넘어갈 때, 선택 상자 테두리가 강조되고 바로 아래에 '필수 입력 항목입니다. 학력을 선택해 주세요.'라는 문구가 나타난다.
    - **3.2.2 학점 범위 초과 오류 알림:** 학점 입력란에 4.5 만점을 넘어서는 수치(4.8)를 적었을 때, 테두리가 강조되고 바로 아래에 '학점은 0.0 ~ 4.5 사이의 값이어야 합니다.'라는 안내가 나타난다.
    - **3.2.3 하단 제출 차단 안내:** 오류가 1건이라도 남아있을 경우 하단에 '수정이 필요한 항목이 2건 있습니다. 입력을 완료해 주세요.' 문구가 뜨며 연봉 확인 버튼이 비활성화된다. 오류를 올바르게 고치는 즉시 정상 화면으로 복구된다.
- **3.3 연봉 진단 결과 화면**
    - **3.3.1 세전 기본급 기준 예상 연봉 카드:** 한국고용정보원 청년패널조사 데이터를 기준으로 산출된 예상 연봉(3,600만 원)과 통계 신뢰 구간(3,400만 ~ 3,800만 원)을 명확하게 제시한다.
    - **3.3.2 동일 집단 내 상대적 위치 분포 밴드:** 나와 같은 학력과 전공을 가진 표본 집단 속에서 내 스펙이 상위 몇 %에 해당하는지, 연차별(초봉, 3년 차, 5년 차)로 어떻게 성장하는지 곡선 그래프로 보여준다.
    - **3.3.3 스펙 반영 내역 및 조건 비교 연결:** 등록된 자격증이나 전공이 연봉 계산에 미친 영향을 짚어주고 다음 단계로 안내한다.
        - 버튼 1: '조건 바꿔서 비교해보기' ➔ 연봉 시뮬레이터 화면으로 연결된다.

## 4.0 연봉 시뮬레이터 (조건 조작 및 비교)

- **4.1 조건 변경 시뮬레이터 화면**
    - **4.1.1 가상 비교 모드 안내 배지:** 화면 상단에 '비교한 조건은 내 스펙에 저장되지 않아요'라는 문구를 띄워, 마음 놓고 다양한 조건을 실험해볼 수 있음을 안내한다.
    - **4.1.2 조건 조작 패널:** 인턴십 기간 추가, 추가 자격증 취득, 어학 점수 상향, 대학원(석·박사) 진학 체크박스를 누를 때마다 새로고침 없이 상단 연봉 숫자가 반응하여 변동액을 계산한다.
    - **4.1.3 실시간 변동 결과 카드:** 현재 내 조건(3,600만 원)과 가상 조건(3,850만 원)을 나란히 대조하여 연봉 차이(+250만 원)와 소요 시간·비용을 직관적으로 보여준다.
- **4.2 시뮬레이터 — 인턴십 상세 비교 화면**
    - **4.2.1 인턴십 6개월 선택 상세 카드:** '선택 중' 배지와 함께 6개월 인턴십을 마쳤을 때 기대되는 연봉 상승폭(+250만 원), 진입 가능한 기업군 변화, 실제 취업까지 걸리는 시간을 현실적으로 짚어준다. 하단에는 '조건을 바꿔 비교한 결과이며, 실제 연봉 상승을 보장하지 않아요'라는 객관적 유의사항이 명시된다.
        - 버튼 1: '이 목표를 대시보드에 저장' ➔ 비회원은 로그인 화면을 거쳐 원래 선택한 인턴 목표를 대시보드 체크리스트에 저장하고, 회원은 즉시 저장한다.
- **4.3 시뮬레이터 — 대학원 진학 비교 화면**
    - **4.3.1 대학원 기회비용 산출 카드:** 대학원(석·박사) 진학 시 소요되는 학비(4학기 등록금 기준) 및 생활비 추정치와 함께, 학사 취업 후 2년간 현업에서 받는 경력 연봉과의 기회비용을 대조한다.
    - **4.3.2 4개년 누적 소득 격차 비교 그래프:** 석사 취득 후 첫 연봉(4,100만 원)과 학사 취업자의 3년 차 도달 연봉 간의 누적 소득 역전 시점을 한눈에 파악할 수 있도록 돕는다.
        - 버튼 1: '이 목표로 준비 시작하기' ➔ 대학원 진학 준비를 목표로 대시보드에 연계 등록한다.

## 5.0 커리어 경로 (선배 이직 궤적 탐색)

- **5.1 이동 경로 지도 화면**
    - **5.1.1 조건 필터링 상자:** 전공, 출발 직무, 연차 구간을 선택하면 한국고용정보원 청년패널조사 표본(1,420명 데이터 기준)에 맞춰 이동 경로 지도가 갱신된다.
    - **5.1.2 첫 취업 및 3년 차 이직 분기 트리:** 첫 직장(중소 솔루션 54% 등)에서 출발한 선배들이 3년 뒤 어떤 산업(중견 이커머스 41%, 금융권 21%, 동일 기업 근속 38%)으로 이직했는지 비율과 선으로 연결된 경로를 보여준다.
    - **5.1.3 대표 이동 경로 요약 카드:** 초봉 3,450만 원에서 3년 차 4,850만 원으로 약 +41% 성장한 대표적인 성공 이직 경로를 하단에 강조한다.
        - 버튼 1: '대표 이직 경로 상세보기' ➔ 대표 경로 상세 화면으로 이동한다.
- **5.2 대표 이직 경로 상세 화면**
    - **5.2.1 경로 프로필 카드:** 이직 시점 구간(1년 미만 / 1년 이상~3년 미만 / 3년 이상)과 3년 차 평균 연봉(4,850만 원), 이동 기업군의 특성을 설명한다.
    - **5.2.2 현재 스펙과 일치하는 요건 목록:** 학사 학위, 정보처리기사 등 내 프로필 중에서 해당 이직 경로의 기본 자격과 맞아떨어지는 항목을 점검한다.
    - **5.2.3 함께 준비해볼 경험 목록:** 대용량 트래픽 처리 경험, AWS 클라우드 배포 경험 등 선배들이 이직에 성공하기 위해 갖추었던 핵심 실무 역량을 제안한다.
        - 버튼 1: '관심 경로로 저장하기' ➔ 비회원은 로그인 완료 후 대시보드에 저장하고, 회원은 즉시 저장한다.

## 6.0 채용 기회 (공고 요건 대조 및 안심 제안)

- **6.1 맞춤 공고 탐색 화면**
    - **6.1.1 근무지 및 경력 필터:** 지역, 신입/경력 구분, 기술 태그를 설정하여 조건에 맞는 공고를 거른다.
    - **6.1.2 스펙 일치도 기반 공고 카드 목록:** 내 스펙 조건과 공고 요건의 일치율(88% 일치 등)과 매칭 키워드가 표시된 카드 목록이다.
        - 카드 클릭 ➔ 해당 공고의 상세 요건 대조 화면으로 연결된다.
- **6.2 관심 공고 보관함**
    - **6.2.1 저장한 공고 목록:** 관심 등록한 공고들의 접수 마감 디데이와 채용 단계(서류 준비 / 지원 완료)를 관리한다.
    - **6.2.2 자동 상태 전환:** 마감일이 지난 공고는 자동으로 마감 처리되어 분리 보관된다.
- **6.3 공고 상세 요건 대조 화면**
    - **6.3.1 공고 원문 요건 카드:** 기업 정보, 담당 업무, 필수 자격, 우대 사항을 꼼꼼하게 열람한다.
    - **6.3.2 1:1 매칭 분석 카드:**
        - 항목 1: 현재 스펙과 일치하는 요건 (컴퓨터공학 전공 등)
        - 항목 2: 보완 시 합격 확률이 높아지는 요건 (단위 테스트 경험 등)
        - 항목 3: 등록 정보에서 확인이 필요한 요건 (데이터베이스 상세 미등록 등)
        - 버튼 1: '내 정보 수정하러 가기' ➔ 누락된 역량을 보완하기 위해 내 조건 수정 화면으로 이동한다.
        - 버튼 2: '공고 저장하기' ➔ 보관함에 공고를 저장한다.
- **6.4 안심 채용 제안 및 정보 보호 화면**
    - **6.4.1 비공개 기업 제안 카드:** 기업이 내 스펙을 보고 보낸 제안(제안 직무, 예상 연봉 범위, 제안 사유)을 확인한다.
    - **6.4.2 개인정보 안심 보호 원칙 안내:** 수락하기 전까지는 이름, 연락처, 세부 학교명이 기업에 절대 노출되지 않으며, 현재 재직 중인 회사의 열람을 차단하는 보호 기능을 제공한다.
        - 버튼 1: '제안 수락 및 연락처 전달' ➔ 사용자가 직접 동의한 경우에 한해 기업 인사팀에 프로필을 안전하게 전달한다.

## 7.0 계정 및 인증 (로그인 및 회원가입)

- **7.1 로그인 화면**
    - **7.1.1 이메일 로그인 상자:** 이메일 주소와 비밀번호 입력란, 로그인 상태 유지 체크박스를 제공한다.
        - 버튼 1: '로그인' ➔ 계정 인증 후 직전에 머물던 화면으로 자동 복귀하여 보류된 저장 작업을 완료한다. 저장 요청 없이 들어온 경우 메인 대시보드로 이동한다.
        - 버튼 2: 'Google 계정으로 계속하기' ➔ 간편 인증을 거쳐 이전 화면으로 복귀한다.
        - 버튼 3: '회원가입' ➔ 회원가입 화면으로 전환한다.
- **7.2 로그인 비밀번호 오류 화면**
    - **7.2.1 비밀번호 오류 안내:** 비밀번호가 8자 미만이거나 틀렸을 때, 입력창 테두리가 강조되고 바로 아래에 '비밀번호는 8자 이상이어야 합니다. (영문·숫자 포함)'이라는 단정한 안내 문구가 뜬다. 오류가 해결될 때까지 로그인 버튼은 비활성화된다.
- **7.3 회원가입 화면**
    - **7.3.1 계정 정보 입력 상자:** 닉네임, 이메일, 비밀번호(8자 이상, 영문·숫자 포함), 비밀번호 확인란을 입력한다. 입력한 닉네임은 서비스 전 화면 우측 상단에 활동명으로 표시된다.
    - **7.3.2 필수 및 선택 약관 동의 상자:** 서비스 이용약관과 개인정보 처리방침에 동의한다.
        - 버튼 1: '회원가입 완료' ➔ 가입 처리 후 직전에 저장 요청을 눌렀던 화면으로 복귀하거나, 첫 가입자의 경우 내 조건 등록 화면으로 이동한다.
- **7.4 회원가입 입력 오류 화면**
    - **7.4.1 비밀번호 불일치 안내:** 두 번 입력한 비밀번호가 서로 다를 때 '비밀번호가 일치하지 않습니다. 다시 확인해 주세요.' 문구가 입력창 바로 아래에 뜬다.
    - **7.4.2 필수 약관 미동의 안내:** 필수 약관을 체크하지 않고 완료를 눌렀을 때, 약관 상자 테두리가 강조되며 '회원가입을 위해 필수 약관에 동의해 주세요.'라는 문구가 뜬다. 두 오류가 모두 해결되어야 가입 버튼이 활성화된다.
