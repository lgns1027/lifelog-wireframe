# LifeLog 전체 서비스 화면별 기획 명세서 및 버튼 목록

본 문서는 LifeLog의 5대 핵심 플로우(FLOW 01 스펙 진단, FLOW 02 미래 연봉 예측 대시보드, FLOW 03 조건 변경 실시간 시뮬레이터, FLOW 04 선배들의 실제 이직 경로 및 목표 관리, FLOW 05 맞춤형 공고 및 기업 안심 채용 제안)의 전체 화면에 배치된 기능과 버튼 목록, 주요 입력 및 시각 요소를 정리한 실무 기획 문서이다.

---

## 1. 공통 GNB 헤더 영역 (전 화면 공통)

* **배치 버튼 및 링크**:
  * `LifeLog (로고)`: 클릭 시 FLOW 01 초기 화면으로 리셋 복귀
  * `스펙 진단` (활성 탭): 현재 진행 중인 진단 플로우
  * `이직 경로`: 향후 서비스 확장 시 이직 시뮬레이터로 전환
  * `채용 제안`: 맞춤형 포지션 제안 탭 전환
* **진행 단계 인디케이터**:
  * `01 학적정보` ➔ `02 역량/자격` ➔ `03 직무선택` ➔ `04 진단결과` (현재 위치에 맞춰 검은색 뱃지 활성화)

---

## 2. 화면별 세부 기능 및 버튼 목록

### Screen 01: 기본 학적 정보 입력 (초기 서식)
* **화면 목적**: 대학생/취준생의 학력, 학교명, 전공, 학점을 처음 입력받는 메인 진입 서식.
* **주요 입력 요소**:
  * 학력 구분 (4년제 대학교 / 전문대학 / 대학원 라디오)
  * 학교명 (읽기 전용 텍스트 필드) 및 본교/분교 체크박스
  * 재학 기간 (입학년도, 입학월, 졸업년도, 졸업월, 졸업 상태 선택)
  * 전공 계열 및 주전공 학과명 텍스트 인풋
  * 졸업 평점 인풋 및 만점 체계(4.5 / 4.3 만점) 선택
  * 병역 구분 (군필 / 미필 / 해당없음 라디오)
* **배치된 버튼 목록**:
  1. `[학교 검색]` (버튼): 대학교 검색 팝업창(Screen 02) 호출
  2. `[전공 검색]` (버튼): 전공 검색 지원
  3. `[다음 단계 (자격/경험 입력)]` (사이드바 버튼): 필수 학적 입력 전까지 비활성화(회색), 전체 입력 완료 시 활성화되어 Screen 03/06으로 이동

---

### Screen 02: 대학교 검색창 노출 (검색 팝업)
* **화면 목적**: 대학알리미 공공데이터 기반으로 정확한 공식 대학교 명칭을 검색 및 선택.
* **주요 입력 요소**:
  * 학교명 검색 키워드 입력창 (예: '한성')
* **배치된 버튼 목록**:
  1. `[✕]` (우상단 닫기 버튼): 검색창을 닫고 Screen 01 서식으로 복귀
  2. `[검색]` (버튼): 입력된 키워드로 일치하는 대학교 리스트 조회
  3. `[선택]` (검색 결과 행별 버튼): 해당 대학교를 본문 서식에 자동 기재하고 팝업 닫힘 (Screen 03으로 전환)
  4. `[직접 입력]` (하단 버튼): 목록에 없는 특수 대학 수동 입력 필드로 전환
  5. `[닫기]` (하단 취소 버튼): 선택 없이 팝업 닫기

---

### Screen 03: 학적 정보 입력 완료 (진행률 반영)
* **화면 목적**: 한성대학교 컴퓨터공학부 등 유효한 학적이 채워지고, 실시간 스펙 완성도(35%)와 대졸자 평균 비교선이 표시된 상태.
* **배치된 버튼 목록**:
  1. `[변경]` (학교명 우측 버튼): 학교 재검색창 호출
  2. `[변경]` (전공명 우측 버튼): 전공 재검색 지원
  3. `[다음 단계 (자격/경험 입력)]` (사이드바 검은색 활성 버튼): 클릭 시 02 역량/자격 서식(Screen 06)으로 이동

---

### Screen 04: 학점 기준 초과 오류 메시지 표시
* **화면 목적**: 4.5 만점 기준에서 4.80 등 초과 숫자를 입력했을 때, 서식 구조를 100% 유지한 채 학점칸 바로 아래에 붉은색 경고를 노출하고 진행을 차단.
* **배치된 버튼 목록**:
  1. `[다음 단계 (자격/경험 입력) - 학점 확인 필요]` (사이드바 비활성화 버튼): 학점 오류가 해결되기 전까지 클릭 불가

---

### Screen 05: 소수 표본 감지 기준 안내창
* **화면 목적**: 유효 표본(30명 미만)이 부족한 특수 학과 입력 시, 상위 계열(공학계열 전체) 표준 데이터로 대조군을 전환함을 안내.
* **배치된 버튼 목록**:
  1. `[계열 기준선으로 계속 진행]` (검은색 강조 버튼): 공학계열 평균 기준으로 대조 전환 승인 후 다음 단계 이동
  2. `[학과 다시 선택하기]` (취소 버튼): 팝업을 닫고 서식으로 복귀

---

### Screen 06: 역량 및 자격증 입력 (초기 서식)
* **화면 목적**: 국가기술자격, 공인 어학, 실무 인턴십 유무를 등록하는 서식.
* **배치된 버튼 목록**:
  1. `[+ 자격증 추가 등록]` (버튼): 국가기술자격 검색창(Screen 07) 호출
  2. `[다음 단계 (희망직무 선택)]` (사이드바 비활성화 버튼): 어학 등 필수 항목 입력 전 대기

---

### Screen 07: 국가기술자격 검색창 노출
* **화면 목적**: 한국산업인력공단 Q-Net 기준 공식 국가기술자격증 검색.
* **배치된 버튼 목록**:
  1. `[검색]` (버튼): 자격증 키워드(예: '정보처리기사') 조회
  2. `[선택]` (행별 버튼): 선택한 자격증을 서식 테이블에 추가하고 팝업 닫힘
  3. `[닫기]` (하단 버튼): 검색 취소

---

### Screen 08: 자격증 및 어학 등록 완료
* **화면 목적**: 정보처리기사 자격증 및 토익 865점이 등록되어 완성도 75%에 도달하고 가산점 통계가 표출된 화면.
* **배치된 버튼 목록**:
  1. `[✕]` (자격증 행 삭제 버튼): 등록된 자격증 삭제 및 완성도 차감
  2. `[점수 수정]` (어학 우측 버튼): 어학 성적 재입력
  3. `[+ 프로젝트 이력 추가]` (버튼): 직무 프로젝트 서식 행 추가
  4. `[다음 단계 (희망직무 선택)]` (사이드바 활성 버튼): Screen 11로 이동

---

### Screen 09: 대학원 진학 기회비용 안내창 (선택 분기)
* **화면 목적**: 학력에서 대학원을 선택했을 때, 학사 2년 실무 경력자와의 연봉 및 기회비용 비교 데이터 안내.
* **배치된 버튼 목록**:
  1. `[선택 취소]` (버튼): 대학원 선택 해제
  2. `[확인하고 적용]` (버튼): 석사 기준선으로 통계 반영

---

### Screen 10: 실무 인턴십 경험 추가 서식
* **화면 목적**: 6개월 이상 실무 인턴 경험(네오위즈아이엔에스)을 입력하여 초봉 가산(+180만 원)을 반영하는 서식.
* **배치된 버튼 목록**:
  1. `[다음 단계 (희망직무 선택)]` (사이드바 검은색 버튼): Screen 11로 이동

---

### Screen 11: 희망 직무 선택 (표준 직업분류 체계)
* **화면 목적**: 한국표준직업분류 7대 직무 대분류 중 1개, 세부 직무(백엔드/서버 개발자) 1개를 단일 선택.
* **배치된 버튼 목록**:
  1. `[대분류 탭 7종]` (IT, 데이터, 경영, 마케팅 등): 우측 하위 세부 직무 목록 갱신
  2. `[세부 직무 라디오 카드 4종]`: 백엔드/프론트엔드/풀스택/인프라 선택
  3. `[최종 검토 단계로 이동]` (서식 하단 및 사이드바 버튼): Screen 13으로 이동

---

### Screen 12: 직무 미선택 오류 메시지 표시
* **화면 목적**: 직무를 고르지 않고 진행하려 할 때 붉은색 테두리 경고 표시.
* **배치된 버튼 목록**:
  1. `[최종 검토 단계로 이동]` (비활성화 버튼): 직무를 1개 선택하기 전까지 이동 차단

---

### Screen 13: 최종 입력 스펙 요약 리포트 검토
* **화면 목적**: 학적, 자격, 어학, 인턴, 직무 5대 입력 내용을 최종 점검하는 요약표.
* **배치된 버튼 목록**:
  1. `[진단 결과 확인하기 ➔]` (대형 검은색 버튼): 데이터 대조 로딩 화면(Screen 14)으로 이동

---

### Screen 14: 고용 통계 데이터 대조 진행 (로딩 1)
* **화면 목적**: 고용노동부 청년패널 1,280건 데이터셋 대조 진행 상태(45%)를 보여주는 화이트 로딩 화면.
* **인터랙션**: 약 2초간 대기 후 Screen 15로 자동 전환.

---

### Screen 15: 목표 직무 예상 연봉 산출 진행 (로딩 2)
* **화면 목적**: 목표 직무 기준 연차별 연봉 성장 곡선 연산 마무리(92%) 화면.
* **인터랙션**: 연산 완료 즉시 Screen 16 알림창 팝업 표출.

---

### Screen 16: 진단 완료 알림창 노출
* **화면 목적**: 3년 차 예상 연봉(4,400만 원) 및 5년 차 도달 직위 요약을 안내하고 대시보드로 유도하는 최종 알림창.
* **배치된 버튼 목록**:
  1. `[대시보드에서 확인하기 ➔]` (정적 검은색 대형 버튼): 대시보드 메인 홈 화면으로 이동

---

## 3. FLOW 02: 미래 연봉 예측 대시보드 기획 명세

FLOW 02는 스펙 진단을 마친 사용자가 로그인 후 마주하는 메인 홈 공간이다. 고용노동부 한국고용정보원 청년패널 통계를 바탕으로 3년 뒤와 5년 뒤 도달 직위 및 예상 연봉, 선배 평균 대비 내 위치를 확인하고, 새로운 스펙 취득 시 실시간으로 연봉을 상향 갱신하는 핵심 허브이다.

### Screen 17: 메인 홈 대시보드 (기본 조회 화면)
* **화면 목적**: 현재 내 스펙으로 산출된 3년 차/5년 차 연봉 구간과 연차별 성장 곡선을 한눈에 조망하는 메인 화면.
* **주요 시각 요소**:
  * 상단 스펙 요약 바: 한성대학교 컴퓨터공학부 / 학점 3.85 / 정보처리기사 / TOEIC 865점 / 인턴 6개월
  * 핵심 연봉 카드 2종:
    * 3년 차 예상 연봉 카드: `4,400만 원` (중위값 기준, 동일 학과 평균 3,920만 원 대비 +480만 원 상회)
    * 5년 차 예상 연봉 카드: `5,400만 원` (예상 도달 직위: 책임/파트장급, 예상 구간: 5,100만 ~ 5,800만 원)
  * 연차별 연봉 성장 궤적 비교 그래프:
    * 회색 실선: 대졸자 평균 궤적 (신입 3,200만 ➔ 3년 차 3,920만 ➔ 5년 차 4,650만)
    * 검은색 굵은 실선: 내 예상 궤적 (신입 3,600만 ➔ 3년 차 4,400만 ➔ 5년 차 5,400만)
  * 다음 최적 행동 1순위 추천 배너: "SQLD 자격증 취득 시 3년 차 연봉 +280만 원 상승 예상 (소요 기간 약 2개월)"
* **배치된 버튼 목록**:
  1. `[스펙 정보 수정]` (우상단 버튼): 학적 및 보유 자격증 갱신 서식으로 이동
  2. `[조건 변경 시뮬레이터로 연봉 올려보기 ➔]` (검은색 강조 버튼): FLOW 03 시뮬레이터로 이동
  3. `[선배들의 실제 이직 경로 확인하기 ➔]` (버튼): FLOW 04 커리어 탐색으로 이동
  4. `[정밀 진단 심층 리포트 열람]` (버튼): Screen 19 심층 리포트 안내창 호출
  5. `[도착한 채용 제안 (2건)]` (우측 상단 뱃지 버튼): FLOW 05 채용 제안함으로 이동

---

### Screen 18: 스펙 갱신 후 상향 재산출 알림 화면
* **화면 목적**: 사용자가 목표로 삼았던 자격증(SQLD)을 취득하여 등록했을 때, 3년 차 예상 연봉이 4,400만 원에서 4,680만 원으로 상향 조정되었음을 시각적으로 보상하는 화면.
* **주요 시각 요소**:
  * 상단 초록색 축하 배너: "축하합니다! SQL 개발자(SQLD) 자격증 등록으로 3년 차 예상 연봉이 +280만 원 상향되었습니다."
  * 3년 차 예상 연봉 카드 갱신: `4,680만 원` (기존 4,400만 원에서 +280만 원 상승 표시)
  * 성장 곡선 상향 이동 애니메이션 상태 고정
* **배치된 버튼 목록**:
